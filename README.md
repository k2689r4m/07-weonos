## 프로젝트 소개
기존에 운영되던 상업용 부동산 중개 시스템을 재구축한 사내 부동산 중개 및 업무관리 플랫폼.

기존 시스템의 데이터와 업무방식을 분석하여 새로운 데이터베이스 및 서비스 구조로 재설계하고, 기존 데이터를 신규 시스템으로 마이그레이션하였다.

매매·임대 매물을 지도에서 검색하고 관리하는 기능을 중심으로 건물·토지·층·임대정보, 고객관리, 담당자 업무관리, 상담 및 작업이력, 매물 상태관리, 출력 및 보고서 등의 실제 부동산 중개업무를 하나의 시스템에서 처리할 수 있도록 구축하였다.

건물 등록 과정에서는 외부 공공데이터를 연동하여 건물 및 토지 관련 정보를 자동으로 수집·반영할 수 있도록 구성하였다.

프로젝트의 Frontend, Backend, DB 및 데이터 처리 전반을 단독으로 개발하였다.

- 지도 영역 검색

### Legacy Data Migration

- 신규 DB 구조 설계

## 성능 및 구조 개선

### 지도 데이터 조회
기존 시스템의 지도 조회 과정에서 데이터 증가에 따른 성능 및 사용성 문제가 발생할 수 있어 지도 전체 데이터를 한 번에 처리하지 않고 현재 지도 화면을 기준으로 필요한 데이터만 조회하도록 구성하였다.

현재 지도 화면의 다음 좌표를 Backend로 전달한다.

- lat_min
- lat_max
- lng_min
- lng_max

Backend에서는 해당 Bounding Box에 포함되는 데이터만 조회하도록 구성하였다.

### Zoom Level 기반 데이터 분리
지도 확대 수준에 따라 동일한 데이터를 계속 조회하는 대신 지도 범위에 맞게 조회 단위를 구분하였다.

- 광역 범위
- 시/구 단위
- 동 단위
- 개별 매물

이를 통해 넓은 지도 영역에서 불필요하게 많은 개별 매물 데이터를 전달하지 않도록 구성하였다.

## 프로젝트 내 역할
기존 상업용 부동산 중개 시스템을 신규 시스템으로 재구축하는 프로젝트를 단독으로 개발하였다.

기존 시스템과 데이터베이스 구조를 분석하여 새로운 DB 구조를 설계하고 기존 데이터를 신규 시스템으로 마이그레이션하였다.

Vue.js 3 기반 Frontend부터 Node.js / Express Backend, MySQL 데이터베이스 및 Stored Procedure까지 전체 서비스 구조를 구현하였다.

특히 대량의 부동산 데이터를 지도에서 효율적으로 조회하기 위해 Bounding Box 및 Zoom Level에 따른 단계별 지도 조회 구조를 적용하였으며, 매매·임대·건물·토지·고객·담당자·업무이력 등의 복잡한 중개업무 데이터를 하나의 시스템으로 통합하였다.

또한 외부 공공데이터 API를 연동하여 건물 및 토지 관련 데이터를 내부 시스템 데이터와 연결함으로써 기존의 수작업 데이터 관리 과정 일부를 자동화하였다.
